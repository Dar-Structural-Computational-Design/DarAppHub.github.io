Effortless updates

You'll never run a stale version again

AppHub quietly checks for new versions in the background and whenever you press Check for updates. Here's all you ever have to do:

  • ✓
    Tools update themselves. The newest published version is fetched in the background — next launch runs the latest, automatically.
  • ✓
    The app updates too. When a new AppHub is released, a gentle amber bar appears.
  • ✓
    One click: Restart. Press it and AppHub relaunches on the new version. Any open tools keep running.
  • ✓
    Works offline. Can't reach the server? AppHub runs the versions you already have and catches up when you're back.

Get started

You're four clicks from done

⤓

Copy the path and run DarAppHub-Setup.msi yourself.

It installs AppHub and adds a shortcut to your Desktop.

K:\Dar_Cads\General\Computational Design Team\Setup\DarAppHub\DarAppHub-Setup.msi

Use Copy path and paste it into File Explorer's address bar, then press Enter.

Then, every day

Open Dar AppHub

Launch it from your Desktop like any other app. First run sets itself up automatically.

Browse & launch

Pick a tool tile and click Launch. AppHub fetches the latest version and runs it.

Automatic Updates

Automatically checks for newest updates every 4 hours. When an update is available, a notification appears. Click Restart to apply.

Keep working

Updates happen on their own. When you see the amber bar, click Restart. That's it.

Good to know

FAQ

Do I need to install anything myself?+
Just a one-time setup. Run DarAppHub-Setup.msi from the K: drive, like previous installations.
Will it slow my computer down?+
No. AppHub is a lightweight launcher. It only does work when you open it or click a tool, and updates run quietly in the background.
I closed AppHub — did my tool close too?+
No. Tools run as independent programs. Closing/Updating AppHub never interrupts a running tool.
What happens if K: is unreachable?+
AppHub is smart enough to keep up with the versions you already have, and quietly catches up the next time the drive is available.
